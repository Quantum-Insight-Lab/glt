# DEV roadmap — 35 шагов

Четыре волны от static verifier до sealed release.

| Wave | Steps | Theme |
|:---:|:---:|---|
| 1 | 01–12 | Static + measurement, Correctness gate |
| 2 | 13–20 | Build evidence, collectors, B1 dashboard |
| 3 | 21–28 | Self-hosted runtime, witness |
| 4 | 29–35 | Runner, Safety gate, sealed release |

## Critical path (bootstrap)

```
01 → 04 → 06 → 08 → 09 → 10 → 12
02 → 05 (parallel after 01)
```

## Gates on roadmap

| Step | Gate |
|---|---|
| 12 | Correctness gate (machine-measured) |
| 28 | Anti-cycle acceptance |
| 32 | Safety prep |
| 35 | Safety gate + sealed release |

Usefulness gate (E01, E04) не привязан к шагу: он требует ≥4 участников, не
писавших граф, и до их появления имеет статус «не проверено». См.
[`../EXPERIMENTS/product-gate.md`](../EXPERIMENTS/product-gate.md).
